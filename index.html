🛠️ 常见同步失败排查：为什么会上传失败？(点击展开)

1. 数据表是否存在？ 必须在 Supabase 的 SQL Editor 运行过建表语句：

create table if not exists trip_rooms ( room_code text primary key, data jsonb not null, updated_at timestamp with time zone default timezone('utc'::text, now()) ); alter table trip_rooms enable row level security; create policy "Allow public all" on trip_rooms for all using (true) with check (true);

2. RLS 权限是否开启写入？ 若 policy 未配置，Supabase 将拒绝所有更新请求。上述 SQL 已包含全权限安全策略。

3. 图片压缩： 旅伴头像已内置自动压缩（最大60KB），确保瞬间秒级上传，不再卡死请求。
